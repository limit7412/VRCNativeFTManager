# 実験的な版の制約

English: [limitations.en.md](limitations.en.md)

本製品は0.xの実験的な版です。ネイティブFace TrackingはVRChat SDKのベータ版の機能で、SDKが正式版になるまでは仕様が変わる可能性があります。本製品も、SDKの正式版に合わせて1.0を出すまでは実験的な扱いとします。

## 現在の版で動くもの

Blendshapes Setのグループ分割、FT全体・目・口・瞳孔・ビゼームのトグル、表情補正（エミュレーション、制限、Eye Sync）、感度、FaceEmoの抑制です。

## ベータクライアントで確かめている途中のこと

- トグルが使うState Behaviorの型と、表情補正の切り替えに使う空のSet（ゲート）が効くか。State Behaviorの型が見つからないときはビルドで警告（KxNFTM-E-05）が出て、トグルと感度だけが効かない
- トラッキングのデータが来ないときの顔のシェイプ（下の節）
- FE-JsT Bridgeにあった「Tracking Controlの再適用」と「FaceEmoとトラッキングのシェイプの重なりの警告」がネイティブFTで必要か。確かめてから入れるかを決める

## パラメーター名が変わる可能性

パラメーターの名前（`KxNFTM/` で始まるもの）は1.0までに変わることがあります。変わった場合は、保存したトグルの値が既定値へ戻ります。

## トラッキングのデータが来ないとき

トラッカーが止まったときや、VRCFaceTrackingを終了したときに、顔のシェイプが0へ戻るか最後の値で止まるかはVRChatが決めます。どちらになるかは、ベータクライアントでまだ確かめていません。
トラッカーを使わない間は、EXメニューの「Face Tracking」を切ってください。Setの重みが0になり、FaceEmoの抑制も解除されます。
同じアバターをトラッカーなしで使う時間が長いなら、トグルの既定値を切っておく方法もあります。
