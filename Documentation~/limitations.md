# 制約と注意点

English: [limitations.en.md](limitations.en.md)

本製品の機能（Blendshapes Setのグループ分割、FT全体・目・口・瞳孔・ビゼームのトグル、表情補正（エミュレーション、制限、Eye Sync）、感度、FaceEmoの抑制）は、VRChatのクライアントで動くことを確かめています。
使うときに知っておきたい挙動を下にまとめます。

## アニメーションの表情とFTが同じシェイプに当たるとき

Face Trackingが有効な間は、Setに入っているシェイプはFTの値で上書きされます。FXのアニメーション（ハンドジェスチャーの表情など）が同じシェイプへ書いた値は見えません。
EXメニューで「Face Tracking」（または「Eye Tracking」「Lip Tracking」）を切ると、そのSetの重みが0になり、アニメーションの値が出ます。
Setに入っていないシェイプ（頬染めなど）は、FT中もアニメーションの値がそのまま出ます。

## 表情補正が作られないシェイプ

表情補正の規則は、書き込み先のシェイプがSetに無いと作られません（ビルド時にKxNFTM-I-01で知らせます）。たとえば眉の内側を上げるシェイプが無いアバターでは、への字口から困り眉を作る補正は効きません。

## トラッキングのデータが来ないとき

トラッカーが止まったときや、VRCFaceTrackingを終了したときは、顔のシェイプは最後の値で止まらず、すぐ元の形（0）へ戻ります。たとえば口を開けたままデータが途絶えると、口は閉じます。
トラッカーを使わない間は、EXメニューの「Face Tracking」を切ってください。Setの重みが0になってアニメーションの表情が出るようになり、FaceEmoの抑制も解除されます。
同じアバターをトラッカーなしで使う時間が長いなら、トグルの既定値を切っておく方法もあります。
